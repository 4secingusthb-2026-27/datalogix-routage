# rapport - Dossier technique final

## Ce qui se fait ici

Le **Chef de projet** centralise ici le rapport PDF final, qui contient :

- la présentation du groupe et la fiche des 4 rôles ;
- les schémas logiques et physiques ;
- les tableaux d'adressage VLSM et les matrices de décision ;
- les captures de validation (tables de routage, sessions eBGP, bascule PBR) ;
- en annexe, les running-config commentées.

## Livraison finale

Une archive zip unique avec : le rapport PDF, un `.txt` par routeur et les fichiers de topologie.
